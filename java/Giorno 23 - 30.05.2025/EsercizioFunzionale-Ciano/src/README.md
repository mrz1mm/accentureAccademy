## ASSUNZIONI

- Il nome corso non può essere nè null nè vuoto;
- Il voto deve essere compreso tra 0 e 30;

- Lo studente non può avere un nome null nè vuoto
- L'età deve essere un numero intero positivo e naturale

- Gli esami hanno un voto compreso tra 0 e 31;

# CONSEGNA

- Ogni studente deve essere iscritto a più di un corso
- Ogni studente ha ricevuto dei voti in ciascun corso che ha frequentato.
- Filtrare gli studenti in base ai corsi seguiti, alla media dei voti, ordinandoli per le loro prestazioni e raggruppare i dati per ottenere la media dei voti per ogni corso
